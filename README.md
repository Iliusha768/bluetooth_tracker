# BatteryDock

Небольшое приложение для Windows: показывает заряд подключённых Bluetooth-устройств отдельными значками с процентами в области уведомлений на панели задач. Щелчок по значку открывает имя устройства, точный процент, кнопку обновления и выход.

## Установка через PowerShell

Откройте PowerShell и выполните две команды:

```powershell
curl.exe -fL https://raw.githubusercontent.com/Iliusha768/bluetooth_tracker/main/install.ps1 -o BatteryDock-install.ps1
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\BatteryDock-install.ps1
```

Первая команда **только скачивает текст установщика** в текущую папку. Его можно открыть в Блокноте перед запуском. Вторая команда показывает консольное меню. При установке можно включить или выключить автозапуск, а перед изменением файлов вводится `yes` или `no`. `RemoteSigned` задаётся только для запущенного процесса PowerShell, постоянные настройки системы не меняются.

После установки в новом окне PowerShell или CMD достаточно ввести:

```powershell
bluetoothdock
```

Меню позволяет запустить значки в панели задач, переустановить программу, переключить автозапуск и полностью удалить её. После установки можно выбрать запуск прямо в том же меню. Когда автозапуск выключен, программа запускается вручную через пункт `1`.

Установка происходит в `%LOCALAPPDATA%\BatteryDock` без прав администратора. Команда `bluetoothdock` находится в `%LOCALAPPDATA%\BatteryDockCommand`, и эта папка добавляется в пользовательский `PATH`. Автозапуск, если выбран, добавляется только для текущего пользователя. При полном удалении приложение закрывается, обе папки и соответствующие записи автозапуска и `PATH` удаляются. Скачанный вручную файл `BatteryDock-install.ps1` в вашей текущей папке можно удалить отдельно. Для установки не требуется .NET SDK: готовый самостоятельный `.exe` берётся из [последнего выпуска](https://github.com/Iliusha768/bluetooth_tracker/releases/latest).

Поддерживается Windows x64. Выпуск автоматически собирается в GitHub Actions при отправке изменений в ветку `main`.

## Запуск

Нужны Windows 10 (версия 2004+) или Windows 11, Bluetooth и [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

```powershell
dotnet run --project .\BatteryDock.csproj
```

Чтобы получить приложение, которое запускается без установленного .NET:

```powershell
dotnet publish .\BatteryDock.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

Файл `BatteryDock.exe` появится в `bin\Release\net10.0-windows10.0.19041.0\win-x64\publish\`. Для компьютера с ARM замените `win-x64` на `win-arm64`.

Если значки скрыты под стрелкой `^`, перетащите их оттуда на панель задач. Обновление происходит раз в минуту; можно обновить вручную через меню значка.

## Какие устройства работают

Приложение читает системное свойство `System.Devices.BatteryLife` у подключённых Bluetooth-устройств. Если для Bluetooth LE его нет, пробует прочитать стандартный GATT Battery Service. Устройства, которые не сообщают заряд Windows или используют свой закрытый протокол, отображаются с `?` и надписью «нет данных». Bluetooth-приёмники с собственными USB-драйверами в эту версию не входят.

Это первая версия для проверки на настоящем компьютере с Windows и Bluetooth-устройствами. Если модель не определяется, приложите её название и скриншот страницы «Bluetooth и устройства» к сообщению об ошибке в репозитории.
